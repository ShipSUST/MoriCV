# Mori CV · 简历助手

Mori CV 是一个 Chrome Manifest V3 扩展，用本地 JSON 管理求职资料，提供快捷复制、网页字段扫描、辅助填写、撤销和填写后核验。当前版本为 **2.0.4**，需要 **Chrome 116 或更新版本**。

## 安装

### 使用程序 ZIP

1. 将程序 ZIP 完整解压到一个准备长期保留的文件夹。
2. 在 Chrome 地址栏打开 `chrome://extensions`，开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的扩展目录。若压缩包内有多层目录，继续进入到该文件所在层。
4. 在 Chrome 工具栏的扩展菜单中固定“Mori CV · 简历助手”，点击图标打开侧边栏。

Chrome 加载的是解压后的目录，请保留该目录。更新文件后，在扩展管理页点击“重新加载”。

### 从源码构建

仓库源码 ZIP 与程序 ZIP 不同：源码需要先构建。准备 Node.js 22 或更新版本和 npm，在项目根目录执行：

```sh
npm run build
```

项目没有需要安装的第三方 npm 依赖。构建会生成 `dist/`，按上面的步骤加载 **`dist/` 目录**。日常使用扩展不需要运行 Node.js。

## 第一次使用

1. 打开侧边栏，点击右上角齿轮进入“个人资料设置”。新安装默认使用空白资料。
2. 在设置中填写资料，点击“另存资料文件”，通过系统文件选择器创建自己的 JSON；已有 Mori CV 资料时，点击“加载资料文件”选择原文件。
3. 后续编辑完成后，点击“保存全部修改”，将草稿写入关联 JSON。留意页面中的文件关联、权限及保存结果提示。
4. 打开招聘网站的简历编辑页，确认扩展拥有该网站的访问权限，再点击侧边栏中的“仅扫描”。
5. 查看识别结果，先尝试少量字段，确认无误后再使用批量填写。

源码中的 `src/examples/mori-cv-profile-example.json` 是可导入的虚构示例；精简程序 ZIP 不包含示例资料。若要参考它，先复制到个人资料目录，再加载这份副本，逐项替换示例内容；不要直接用示例投递。

## 资料如何组织

| 资料类型 | 用途与边界 |
| --- | --- |
| 44 个固定字段 | 基本信息 36 项、求职偏好 8 项。名称、分类和匹配别名由程序维护；你填写主值，以及该字段支持的候选或路径。不能新增、删除或改名。 |
| 9 类结构化记录 | 教育经历、实习/工作经历、项目经历、论文成果、奖项荣誉、技术技能、外语能力、资格证书、亲属关系。每类可维护多条记录。 |
| 其他 | 自定义名称与内容，适合汇总、备注或额外资料。仅供复制和显式定点填入，不参与自动扫描匹配或一键填写。 |

固定字段只读取各自的主值，空值不会从教育等记录中补齐。例如，最高学历需要单独填写；出生地与籍贯、实际毕业时间与预计毕业日期也分别维护。

下拉候选用于你认可的不同写法：先匹配主值，再依次尝试候选。地区路径按行分级，每一级可用逗号列出候选；找不到选项或存在歧义时停止。扩展不会自行推断替代选项。

日期建议使用 `YYYY-MM` 或 `YYYY-MM-DD`。网站要求完整日期而资料只有年月时，需要你补齐，扩展不会猜测具体日期。

## 填写与核验

- **复制或定点填入**：先点击网页中的目标输入框，再点资料旁的“填入”；也可复制后手工粘贴。结构化记录主卡片的“填入”会寻找整组字段，展开后的子字段可定点填一个框。
- **仅扫描**：查看当前页面可识别的字段和匹配情况，不执行填写。
- **一键填写当前简历**：处理可确认匹配的字段；支持的记录类别也可使用“批量填入”。部分适配器能添加重复记录，另一些仅填写现有编辑器，请留意结果提示。
- **撤销本次填写**：尝试恢复当前页面最近一次扩展填写。字段已被你再次修改、页面结构变化或控件无法恢复时，可能无法撤销，需检查结果。
- **重新扫描并核验**：检查本次填写的值是否仍显示在页面上。由你保存并刷新或重新进入页面后，可检查是否显示“刷新/跳转后仍存在”。

条目旁的绿色 `✓` 表示扩展确认了当前标签页的填写结果。页面回读与刷新后核验都不能单独证明网站服务器已正确保存全部资料；仍需检查网站自身的保存结果。

默认保留已有内容。启用“覆盖已有内容”仍需确认；已有结构化记录中的不同值按组确认。求职意向中的岗位、职业和工作城市需要手动选择。

设置中的匹配灵敏度预设为保守 88、标准 78、灵敏 60，也可自定义 0–100。分数衡量字段文字的匹配程度，**不是填写正确率**。降低门槛会扩大尝试范围，也更需要复核；专用适配器的精确记录映射不依赖此门槛，资料身份和日期精度等限制仍然有效。

## 网站与控件范围

| 路径 | 支持范围 |
| --- | --- |
| 通用引擎 | 可见文本框、文本域、原生下拉框、单选/多选组、日期/月控件、可编辑区域，以及部分自定义下拉与级联控件；重复区块需要明确结构和高置信字段。包含部分 ByteDance Universe Design 控件兼容逻辑。 |
| MokaHR | 已识别的平台表单与 DJI 白标结构，包括部分重复记录、Sugar Design 下拉和日期控件。 |
| Zhiye（智业） | 已识别的 Phoenix 表单；中国人寿、Seyond、上海银行、南京证券和三一另有准确租户及结构限定的补充适配。不同租户支持的模块不同。 |
| 飞书招聘 | 已识别的表单及部分日期、重复记录控件。 |
| 51job | 限 `xyz.51job.com` 的 `External/MyResume/FillInResume.aspx` 模板中已识别的基本信息、固定教育、IT 技能、实习/工作和自我评价；仅处理当前已有编辑器。 |

Seyond 的论文/奖项、南京证券的亲属、三一的论文等补充映射只作用于已识别结构。三一论文填写要求当前编辑器已明确选择“是”和“论文”，扩展不会替你切换到该分支。缺少记录编辑器、日期信息或明确候选时，按提示手动处理。

网站名称相同不代表所有页面都兼容；平台改版也可能使识别失效。扫描和匿名测试结果不能替代实际页面检查。不处理密码、验证码、文件上传、隐藏或禁用字段、Chrome 受保护页面、跨域 iframe、关闭式 Shadow DOM 和画布控件。无法可靠识别的控件请手工填写。

## 本地文件与隐私

关联的 **JSON 是唯一资料主档**，`chrome.storage.local` 是工作副本，不使用 Chrome Sync。每次复制、扫描匹配和填写前会重新读取并校验 JSON；未关联文件、授权失效、读取失败或格式错误时，资料操作会暂停，缓存可供查看，撤销和历史填写核验仍可使用。

“保存全部修改”先写 JSON，再更新缓存；保存前会检查文件是否被其他程序修改。读取旧格式只迁移运行副本，显式保存或另存前会显示迁移清单并允许取消；确认后先触发原始 JSON 备份下载，请确认备份下载完成。

扩展没有账号、遥测、远程脚本或向外发送资料的网络请求。资料文件和浏览器中的本地缓存是明文，请保存在可信位置并自行备份，避免提交到公开仓库。填写到网页后，目标网站可以读取这些内容。

扩展申请以下 Chrome 权限：

| 权限 | 用途 |
| --- | --- |
| `activeTab`、`scripting` | 访问当前网页并注入本地扫描、填写脚本。 |
| `sidePanel` | 显示侧边栏。 |
| `storage` | 保存本地工作副本和设置。 |
| `clipboardWrite` | 复制资料。 |
| `http://*/*`、`https://*/*` | 在不同招聘网站使用本地脚本，避免逐站重复授权；Chrome 受保护页面仍不可访问。 |

## 开发与验证

源码位于 `src/`，`dist/` 由构建生成。修改源码后可执行：

```sh
npm run check
npm test
npm run build
```

`npm run verify` 依次执行以上三项。`npm run privacy` 检查默认资料，并扫描源码、构建产物、全部测试、脚本和指定公共文档；`npm run fixture` 启动本地匿名演示表单。扫描不涵盖内部记录、忽略目录或 Git 历史，不能代替发布审计。自动浏览器回归使用独立测试 Chrome，不能连接正在编辑真实招聘表单的浏览器。可复现范围和可选测试前提见 [开发说明](docs/DEVELOPMENT.md)。
