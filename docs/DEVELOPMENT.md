# 开发与测试

项目运行代码没有第三方 npm 依赖。建议使用 Node.js 22 或更新版本；Chrome 扩展运行时要求 Chrome 116 或更新版本。

## 目录

- `src/`：扩展运行源码，包含空白默认模板和单独标明虚构内容的资料示例。
- `scripts/`：检查、构建、匿名夹具与开发工具。
- `tests/`：单元测试及匿名浏览器夹具。
- `dist/`：执行 `npm run build` 后生成的扩展目录，不手工修改。

修改源码后运行 `npm run verify` 与 `npm run privacy`。后者在本地存在关联资料文件时会只读对照高信号内容，不打印个人值；未提供私人文件时无法进行该对照。范围包含运行源码与产物、全部测试和脚本，以及 README、LICENSE、package.json、GLOSSARY 和指定公共开发文档；不包含内部记录、忽略目录或 Git 历史，不能用一次零命中结果证明任意文件均可公开。

## 浏览器回归

`npm run fixture` 启动本地匿名页面，`npm run e2e` 通过本地调试端口驱动专用测试 Chrome。使用干净的独立测试配置和端口；不要连接已有登录状态或未保存表单的日常浏览器。测试脚本可能导航、刷新和填写页面。

一些可选的 51job 日历/字典回放依赖额外的第三方组件文件，部分历史对照路线依赖旧版测试快照。这些文件不随源码分发。缺少前提时不要把对应路线列为已通过，也不要从真实用户浏览器抓取个人表单来补夹具。常规构建和单元测试不依赖这些材料。

匿名夹具验证可观察的本地行为，不代表所有真实网站模板兼容，也不证明招聘网站已保存资料。新增适配应先观察公开控件结构、制作虚构夹具，再经实际资料投影与公开消息入口验证；不能把个人填写值加入测试或错误断言。

## 分享前检查

程序 ZIP 只包含经过清单核对的运行文件，不包含示例资料、开发工具、私人 JSON 或 Git。源码快照包含虚构示例，和程序 ZIP 用途不同。

只从发布白名单导出源码；不要对开发目录整体压缩，也不要直接推送包含私人开发记录的旧 `.git`。资料文件、浏览器缓存、截图、日志、备份、旧安装包和本地交接记录均留在本地。提交作者信息和提交消息也需要检查。
