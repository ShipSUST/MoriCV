# 安装与使用

## Chrome 安装

1. 将包含本文件和 manifest.json 的扩展目录放在固定且可信的位置。开发版本直接使用 dist 文件夹。
2. 在 Chrome 地址栏打开 `chrome://extensions`。
3. 开启右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择包含本文件和 `manifest.json` 的文件夹。
6. 将“Mori CV · 简历助手”固定到工具栏。

Windows 版 Chrome 不支持普通用户可靠地直接安装本地 `.crx`，因此请使用上述“加载已解压”方式。

## 填写流程

1. 打开招聘网站简历编辑页。
2. 首次安装时，确认 Chrome 显示的网站访问权限；普通 HTTP/HTTPS 招聘网页会默认获得访问权。
3. 点击扩展图标打开侧边栏。以后切换到其他普通招聘网站时无需再次逐站授权。
4. 普通资料先点击网页中的目标输入框再点“填入”；教育、项目、奖项等结构化母词条的“填入”会填写一整组，展开后的子字段可单独定点填写。
5. 点击“一键填写当前简历”；MokaHR、Zhiye、飞书招聘及已识别的 51job 表单使用专用适配，其他网站使用高置信通用匹配。各结构化大类顶部也可不限条数批量填入，并显示处理进度。
6. 设置页中的资料条目会在侧栏显示，未填写的条目显示“尚未填写”。固定字段和支持的结构化记录可参与自动填写；末尾“其他”仅用于复制或显式定点填入，不参与一键填写。
7. “填入”或“一键填写”成功后，来源条目旁会显示绿色 `✓`。它只表示已写入当前网页，不表示招聘网站已经保存。
8. 如果填错，可在页面刷新前点击“撤销本次填写”；复杂控件可改用“复制”。
9. 检查网页中的绿色高亮字段以及边栏中的跳过原因。
10. 手动点击招聘网站的保存按钮；扩展不会点击保存、提交或投递。
11. 由你刷新或重新进入页面后，点击“重新扫描并核验”。

如果升级后仍显示“该插件想要访问此网站”，请在 `chrome://extensions` 中重新加载扩展并接受新增权限，或在扩展图标右键菜单的“可读取和更改网站数据”中选择“在所有网站上”。Chrome 内部页面和扩展商店仍不可访问。

## 数据安全

- 关联后的 JSON 是唯一主档；Chrome 扩展本地存储保存明文运行缓存。旧格式只迁移运行副本；显式保存前会显示迁移清单并触发原文件备份下载，请确认下载完成。
- 每次复制、扫描匹配或填写都会重新读取关联 JSON；旧按钮按稳定标识取新值，批量操作使用一份固定快照。
- 文件未关联、授权失效、读取失败或格式错误时暂停复制和填写；撤销与原填写核验继续可用。
- 设置页修改先保留为草稿，成功写入 JSON 后才更新 Chrome 工作副本。外部修改冲突会阻止覆盖。
- 新安装默认为空白资料模板，不含作者资料。可在设置页填写后点击“另存资料文件”，自行选择保存 JSON 的位置。
- 在另一台电脑安装后，点击“加载资料文件”选择该 JSON，即可导入整个资料库。
- 个人 JSON 应与程序分开保存在可信目录，勿提交到公开仓库。首次仍需在系统文件窗口中确认位置，这是 Chrome 的安全限制。
- 导出的 JSON 也包含明文敏感资料，请放在可信位置。
- 资料填入网页后，目标网页自身可以读取，风险与手工输入相同。
- 不要在资料库中保存密码或短信/图形验证码。

## 匿名示例资料

精简程序 ZIP 不包含示例资料。源码的 `src/examples` 文件夹中包含：

- `mori-cv-profile-example.json`：可直接导入的完整匿名示例资料。
- `README.md`：字段结构、导入步骤、日期格式以及安全注意事项。

示例中的人物、学校、公司、项目、证件号码和联系方式全部为虚构内容。导入后必须替换成自己的资料；不要直接使用示例内容投递。

## 日期与地区

51job 目前限 `xyz.51job.com/External/MyResume/FillInResume.aspx` 已观察的基本信息、固定两段教育、IT 技能、工作经历和自我评价。侧栏显示“51job”；只处理当前已有编辑器，不自动翻页、增删记录或保存。资料对应关系、选项或日期精度不明确时提示手动处理。

Seyond 智业目前补充 `seyond.zhiye.com/form` 的论文/专著与获奖情况。只填写已有编辑器；论文年度/期次留空供手动处理，完整日期缺日或级别候选不匹配时跳过，不自动补日或替换等级。已确认归属的单值菜单可在批量填写中自动切换，无需先手动关闭；某个级别缺候选时继续处理其他日期和记录。未知或多选浮层仍需手动处理。

教育入学、毕业时间和实习开始、结束时间支持逐条记录的可选日期路径：每行一层，依次为年、月、日，同层候选以逗号分隔。主日期决定目标；路径与主值矛盾时停止。日期无需配置路径也能自动拆分。网站只支持年月时忽略日；要求完整日期但资料缺日时提示补充资料。

地区路径按省、市、区逐级选择；单级下拉使用填写值与下拉候选。Moka 出生年月和智联日历使用各自的日期操作方式。智联仅填写当前可编辑模块，其他记录需要你手动保存或打开。
