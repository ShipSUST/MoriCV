# Mori CV 示例资料使用说明

本目录随源码提供，用于帮助新用户理解资料 JSON 的结构并完成第一次导入；精简程序 ZIP 不包含此目录。

## 文件说明

- `mori-cv-profile-example.json`：可以直接导入 Mori CV 的完整匿名示例。
- 示例中的姓名、学校、公司、项目、证件号码、联系方式和获奖信息全部是虚构内容，仅用于演示格式。
- 请勿直接用示例资料投递简历。导入后应逐项替换为自己的真实资料。

## 导入步骤

1. 安装扩展并点击工具栏中的 `Mori CV` 图标。
2. 点击侧栏右上角齿轮，进入“资料设置”。
3. 点击“加载资料文件”。
4. 选择本目录下的 `mori-cv-profile-example.json`。
5. 阅读覆盖提示，确认后完成导入；建议加载前先复制示例到自己的资料目录。
6. 修改所有示例值，点击“另存资料文件”建立自己的资料主档。
7. 后续使用“保存全部修改”写入这份关联文件，不要将个人值写回源码示例。

导入操作会覆盖当前 Chrome 配置中已有的 Mori CV 资料。如果你已经录入过内容，请先点击“另存资料文件”备份。

## JSON 的两类数据

### `entries`：单值资料

schema9区分44个固定字段与末尾「其他」。固定字段名称/分类/别名在程序内，JSON只存个人数据：

- `id`：稳定且不能重复的内部标识。已有条目的 ID 不建议修改。
- `category`、`label`：仅其他项保存，category固定为“其他”，label是自定侧栏名称；固定行不需要这两项。
- `value`：需要复制或填写的内容。
- 固定字段`aliases`由程序维护，不放在个人JSON；记录类现有别名仍可编辑。
- `optionValues`：下拉框或单选框可能出现的候选写法。

只有非空固定字段参与自动匹配。其他只保存ID/分类/名称/值，可复制或显式定点填入，不参与一键填写、扫描建议或自动来源冲突检查。固定字段只用各自主值，不从记录补齐。

### `records`：可重复的结构化经历

用于一个人可能拥有多条的内容：

- `educations`：教育经历。
- `internships`：实习或工作经历。
- `projects`：项目经历。
- `papers`：论文。
- `awards`：竞赛奖项与荣誉；每条用 `awardCategory` 区分。
- `programmingLanguages`：编程语言或通用技能。
- `foreignLanguages`：外语能力。
- `certifications`：资格证书。
- `relationships`：亲属关系。

每条记录必须有全文件唯一的 `id`。例如两个项目不能使用同一个 `id`，项目和奖项之间也不能共用同一个 `id`。

结构化记录还可以包含：

- `displayName`：侧栏显示名称；留空时根据记录内容自动生成。
- `summary`：侧栏显示及复制使用的整段摘要；留空时自动生成。主“填入”按钮填写整组分字段，不把摘要塞入一个框。
- `aliases`：该记录的补充匹配名称。
- `fieldOptions`：各分字段的用户下拉候选，按记录独立保存。先匹配字段主值，再依次尝试候选，不从模板枚举推断。

同类分字段别名保存在 `recordTemplates[集合名].fieldAliases` 中，供该类所有记录共用。教育的 `educationLevel` 是学历，`academicDegree` 是学位；旧 `degree` 原值和候选迁入学历，学位不自动推断。

普通词条的 `pathValues` 是二维数组：外层从上到下表示级联层级，每层数组按顺序列出该级候选。设置页使用换行分级、逗号分隔该级候选；旧一维路径会按原顺序迁入，每级一个候选。

## 汇总文本与逐条记录

部分网站只有一个大文本框，部分网站要求点击“添加”后逐条填写，因此示例同时提供：

- `skills.summary`、`awards.summary` 等汇总文本：面向大文本框。
- `records.programmingLanguages`、`records.awards`、`records.certifications` 等结构化记录：面向多条表单。

汇总条目只用于确实需要“多项合并为一段”的场景，例如全部奖项汇总。单个教育、实习、项目或论文不应再复制到 `entries`；侧栏摘要会从对应结构化记录生成。

## 日期格式

建议使用以下格式：

- 年月：`2026-09`
- 完整日期：`2026-09-19`
- 仍在进行：结束时间留空，并设置 `current: true`

教育经历若需要精确到日，直接在对应教育记录的 `start` 和 `end` 中保存完整日期；不要把起止日期合并成一段文字。

不要把年月写成 `2026年9月` 放入结构化日期字段；侧栏会自动转换显示格式，填写引擎则需要标准格式操作日期控件。

## 安全提醒

- JSON 是 Mori CV 的主档，`chrome.storage.local` 只保存运行缓存，不使用 Chrome Sync，也不上传到服务器。建立文件关联后，“保存全部修改”会先写入 JSON，再更新缓存。读取旧格式只迁移运行副本；显式保存前显示迁移清单并触发原始 JSON 备份下载，请确认下载完成；已有历史备份不会自动删除。
- 导出的 JSON 同样是明文，应保存在可信目录，不要发到公共仓库或聊天群。
- 不要在资料中保存密码、短信验证码、图形验证码或账号恢复信息。
- 扩展只填写页面，不会自动点击保存、提交或投递。填写后必须由用户检查并手动保存。
